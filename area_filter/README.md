# Area Filter

基于 YOLO 标注格式的图片面积筛选工具。

## 功能

- 扫描指定目录中的图片及对应的 YOLO `.txt` 标注文件
- 计算每个标注框的像素面积，统计面积分布
- 根据用户指定的面积范围筛选图片
- 筛选后的图片和标注自动复制到输出目录

## 使用方法

```bash
python area_filter.py
```

运行后按提示输入：

1. 图片目录路径
2. 面积筛选范围（格式：`最小值~最大值`，如 `1000~5000`）
3. 输出目录路径

## 输出结构

```
output/
├── images/    # 筛选后的图片及 .json 文件
└── labels/    # 筛选后的 YOLO .txt 标注文件
```

## 依赖

- opencv-python
