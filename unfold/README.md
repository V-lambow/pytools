# Unfold

递归文件夹展平复制工具，将多层嵌套目录中的所有文件复制到单一输出目录。

## 功能

- 递归遍历源文件夹及其所有子目录
- 将所有文件复制到同一输出目录
- 自动处理文件名冲突（添加 `_1`, `_2` 等后缀）
- 保留文件元数据（shutil.copy2）
- 支持 GUI 文件夹选择（有 tkinter 时）或命令行输入

## 使用方法

### 命令行参数

```bash
# 指定输入和输出路径
python copy_files.py --input <源文件夹> --output <输出文件夹>

# 仅指定输入路径，输出到默认 ./output
python copy_files.py -i <源文件夹>

# 无参数时，弹出 GUI 对话框选择输入和输出文件夹
python copy_files.py
```

| 参数 | 缩写 | 说明 |
|------|------|------|
| `--input` | `-i` | 源文件夹路径 |
| `--output` | `-o` | 输出文件夹路径（默认 `./output`） |

### GUI 模式

无命令行参数时：
- 弹出输入文件夹选择对话框
- 再弹出输出文件夹选择对话框（留空使用 `./output`）

无 tkinter 环境时通过命令行输入路径。

## 依赖

- 标准库即可（os, shutil, pathlib）
- 可选：tkinter（用于 GUI 文件夹选择）
